# 知远风物志 GEO内容生产工作流程 V1.0

> 本流程将《选题卡模板V1.0》《企业官网GEO_SEO内容创作规范V1.4》《GEO-SEO文章优化补充规范V1.1》三个规范串联为一个从选题到上线的完整工作流程。
> 适用范围：知远风物志所有GEO文章的生产、优化和部署。
> 生效日期：2026-09-08
> V1.1更新：基于墟日趁墟试点优化验证，阶段3新增素材库调用、个人署名与研究视角、观众质疑模块；阶段4新增文风一致性检查（7层控制体系）；阶段5新增禁止事项检查。

---

## 一、三个规范的定位与关系

| 规范 | 定位 | 使用阶段 | 核心作用 |
|---|---|---|---|
| 选题卡模板V1.0 | 选题前置确认工具 | 阶段1：选题 | 确保选题有价值、有史料、有边界、无风险 |
| 创作规范V1.4 | 内容创作完整标准 | 阶段2-4：史料→创作→质检 | 确保内容符合GEO/SEO要求、史料严谨、结构完整 |
| 补充规范V1.0 | 优化阶段补充标准 | 阶段5：优化 | 确保标题、首段、内链、技术SEO等细节到位 |

**关系**：选题卡是入口，创作规范是主体，补充规范是收尾。三者配合使用，如有冲突以补充规范为准。

---

## 二、完整工作流程（7个阶段）

```
阶段1：选题确认 → 阶段2：史料准备 → 阶段3：内容创作 → 阶段4：内容质检
     ↓                                                          ↓
阶段7：分发推广 ← 阶段6：部署上线 ← 阶段5：GEO/SEO优化
```

## 三、各阶段详细说明

### 阶段1：选题确认

**使用规范**：《选题卡模板V1.0》

**输入**：
- 地方志素材库（E:\仓库\本地拆解md）
- 已有文章列表（避免重复）
- 搜索关键词趋势（可选）

**操作步骤**：
1. 从地方志素材库中筛选有价值的选题
2. 填写选题卡9个部分：
   - 基本信息（选题名称、编号、栏目、平台、日期）
   - 选题判断（核心问题、常见误解、要纠正的判断、核心结论、传播点）
   - 史料底稿（主要史料3条、出处完整、卷次确认、待核内容）
   - 范围边界（地域、时间、讨论什么、不讨论什么、不能写的内容）
   - 观点分层（史料事实、作者解释、可争议判断、现代意义、反面观点）
   - 平台拆分（官网母版标题、公众号方向、知乎方向、小红书方向）
   - 关联与回流（官网路径、相关文章、可复用FAQ、新增FAQ、回流方式）
   - 风险检查（迷信表述、以偏概全、推论当事实、内容重复、需补史料）
   - 结论（是否通过写作、未通过原因、需补充材料、复审日期）
3. 选题卡审核通过后才能进入下一阶段

**输出**：
- 完整填写的选题卡（.md文件）
- 选题编号（GEO-XX-XX格式）

**通过标准**：
- [ ] 核心问题清晰，是搜索者会问的问题
- [ ] 至少3条史料，出处完整（书名+卷次+类目）
- [ ] 范围边界明确，不泛化
- [ ] 风险检查全部通过
- [ ] 与已有文章无主题重复（或角度明确不同）

**注意事项**：
- 选题卡是"先卡后写"的强制要求，未填卡不得写稿
- 选题卡的"核心问题"直接决定文章的问题式标题
- 选题卡的"史料底稿"必须来自实际地方志，不得编造

### 阶段2：史料准备

**使用规范**：《创作规范V1.4》第1.6-1.7节（史料严谨度、出处精确描述）

**输入**：
- 阶段1输出的选题卡
- 地方志素材库

**操作步骤**：
1. 根据选题卡的史料底稿，从地方志素材库中提取完整原文
2. 核实每条史料的出处：
   - 书名（含修纂年代和刊本年代）
   - 卷次或志类（按原书实际结构标注）
   - 类目（精确到具体类目）
   - 原文摘抄（尽量完整，不省略）
3. 建立范围与证据矩阵（创作规范V1.4第1.7节）：
   - 研究对象、实际地点、历史时期
   - 旧志中的原称谓
   - 直接史料、传统文献背景
   - 作者推论和明确不能推出的结论
4. 整理概念分层（创作规范V1.4第1.6节）：
   - 明确区分研究对象的不同层次
   - 列出本文讨论哪些、不讨论哪些

**输出**：
- 史料底稿（完整原文+出处）
- 范围与证据矩阵
- 概念分层表

**通过标准**：
- [ ] 每条史料四要素齐全（书名+卷次+类目+原文）
- [ ] 无"卷次待核""相关记载"等模糊表述
- [ ] 范围与证据矩阵建立完成
- [ ] 概念分层清晰，避免概念混杂
- [ ] 至少2本不同地方志的原文引用

### 阶段3：内容创作

**使用规范**：《创作规范V1.4》第1-8节 + 《补充规范V1.1》第1-3节、第9-12节（标题、首段、个人署名、内容结构、素材库调用、文风控制、禁止事项）

**输入**：
- 阶段2输出的史料底稿、范围与证据矩阵、概念分层
- 选题卡
- 口播素材库（`E:\风俗民俗\风俗民俗\口播素材库\`）

**操作步骤**：
1. **确定问题式标题**（补充规范V1.1第1节）：
   - 格式：`[核心问题]？[副标题/关键词补充]`
   - 三种类型：是什么型、为什么型、怎么/如何型
   - title标签：问题式标题 + `｜知远风物志`
   - h1标签：问题式标题（可换行）

2. **撰写首段**（补充规范V1.1第2节）：
   - 第一层：场景化引入（1句，**必须具体化**，有具体地名/时间/人物，不超过80字）
   - 第二层：直接答案式概述（2-3句）
     - 第一句直接回答标题问题
     - 第二句补充核心知识点
     - 第三句说明研究范围和材料来源
   - 禁止使用"本文主要讨论""在讨论之前"等学术化开场

3. **调用口播素材库**（补充规范V1.1第10节，**强制环节**）：
   - 从`05_文章骨架库.md`选结构（参考，适配GEO文章要求）
   - 从`07_全部观点清单库`选主观点和分观点
   - 从`03_写作手法套式库.md`选2-3个推进手法（不超过4个）
   - 从`04_价值观标签库.md`选2-3个价值观（作为隐性立场，不直接标注）
   - 从`01_原句与句式库.md`选表达（转化为书面语，不直接用口语）
   - 从`08_观众质疑与回应库.md`选1-2个质疑点（主题有争议时）
   - 从`02_事实与案例库.md`选事实
   - 从`09_收尾与结语库.md`选结尾方式（优先首尾呼应，禁止千篇一律的总结）

4. **按文章结构模板撰写正文**（补充规范V1.1第9节）：
   - hero区：hero-category只显示分类标签（**不展示内部编号**），hero-meta包含"作者：王知远"
   - overview-card：场景化引入+直接答案
   - related-read：内链互引
   - **研究者手记模块**（补充规范V1.1第3节，**强制**）：基于真实地方志阅读经历，100-150字，第一人称
   - 一、概念分层（必须有，禁止用"不是A也不是B重要的是C"抽象范式句，A和B必须具体说清楚）
   - 二、历史渊源（300-400字，时间线清晰，可用M11片段插入后解读手法）
   - 三、地域差异（400-500字，至少2组对比，用表格）
   - 四、传统做法（300-400字，步骤清晰，可用M01从浅入深手法）
   - **观众质疑模块**（补充规范V1.1第9.3节，主题有争议时强制）：1-2个真实质疑+基于史料的回应
   - 五、现代意义与常见误区（200-300字，2-3个误解，融入价值观标签）
   - 六、常见问题FAQ（3-5个，口语化搜索词，**答案结构必须多样化**，不能同一模板）

5. **添加参考资料**（创作规范V1.4第1.7节）：
   - 每条包含：书名（含版本）+卷次/志类+类目+原文摘抄
   - 零泛化规则：无"相关记载""等记载"等模糊表述

6. **添加免责声明和研究范围声明**（创作规范V1.4第1.5节）：
   - 免责声明："本文为岭南传统文化研究，所引内容均出自地方志史料，不构成任何择日、起名、运势建议。"
   - 研究范围声明：逐一列出实际覆盖的府县
   - **统一放页尾footer，正文里不出现"本文不讨论XX"免责式表述**

7. **添加服务转化区域**（补充规范V1.1第7节）：
   - 位于正文结束后、footer之前
   - 文案使用"传统民俗日期咨询"
   - 链接到 `/guide-form`

8. **文风一致性通读**（补充规范V1.1第11节，7层控制体系第7层）：
   - 通读全文，检查是否有语焉不详、上下断层、文风怪异
   - 检查手法切换是否有过渡句
   - 检查是否只借结构手法、不借口语表达
   - 检查手法数量是否在2-3个（不超过4个）

**输出**：
- 文章Markdown源文件（.md）
- 文章HTML文件（.html，含完整技术SEO标签）

**通过标准**：
- [ ] 标题是问题式（是什么/为什么/怎么）
- [ ] 首段有场景化引入（具体化，有具体地名/时间/人物）+直接答案式概述
- [ ] 已调用口播素材库（2-3个价值观+2-3个手法+1-2个质疑）
- [ ] hero-meta包含"作者：王知远"
- [ ] 有研究者手记模块（基于真实地方志阅读经历，100-150字）
- [ ] hero区不展示内部编号
- [ ] 概念分层已完成，无抽象范式句
- [ ] 六大板块完整
- [ ] 主题有争议时有观众质疑模块
- [ ] 至少引用2本地方志原文，出处完整
- [ ] FAQ 3-5个，问题是口语化搜索词，答案结构多样化
- [ ] 免责声明和研究范围声明已加（统一放页尾）
- [ ] 服务转化区域已加
- [ ] 文风一致性通读通过（无语焉不详、上下断层、文风怪异）
- [ ] 无预测/改运/断言式内容
- [ ] 无以偏概全、无推论过度、无绝对化表述

### 阶段4：内容质检

**使用规范**：《创作规范V1.4》第九节（质检标准）+ 《补充规范V1.1》第11-13节（文风控制、禁止事项、检查清单）

**输入**：
- 阶段3输出的文章（.md和.html）

**操作步骤**：
1. **内容质检**（创作规范V1.4第9.1节）：
   - 标题、首段、概念分层、六大板块、史料引用、FAQ、免责声明等
2. **史料严谨度质检**（创作规范V1.4第9.2节）：
   - 无以偏概全、无推论过度、史料事实与推论分离、无绝对化表述等
3. **GEO质检**（创作规范V1.4第9.2节）：
   - 关键词密度、首段长度、FAQ格式、地域差异表格、实体关联等
4. **SEO质检**（创作规范V1.4第9.3节）：
   - Title标签、Meta Description、H1/H2/H3、内链、URL、图片Alt等
5. **合规质检**（创作规范V1.4第9.4节）：
   - 无封建迷信断言、无硬广推销、免责声明、史料引用准确
6. **协作质检**（创作规范V1.4第9.5节）：
   - 选题卡已完成、母版主题清晰、公众号能回流官网、各平台核心事实一致
7. **参考资料质检**（创作规范V1.4第9.5节）：
   - 每条四要素齐全、卷次类目完整、原文摘抄完整、无模糊标注
8. **文风一致性质检**（补充规范V1.1第11节，7层控制体系）：
   - 手法使用条件确认：每个手法的使用条件是否满足
   - 价值观风险边界确认：每个价值观的风险边界是否遵守
   - 手法是否服务于史料逻辑（不是为了用手法而用手法）
   - 手法切换是否有过渡句
   - 是否只借结构手法、不借口语表达
   - 手法数量是否在2-3个（不超过4个）
   - 全文是否有语焉不详、上下断层、文风怪异
9. **禁止事项质检**（补充规范V1.1第12节）：
   - 无抽象范式句（如"不是A也不是B重要的是C"）
   - 正文无"本文不讨论XX"免责式表述
   - hero区无内部编号展示
   - 无模板化表达（所有文章结构不完全一样、FAQ答案不都是同一模板、结尾不都是"总结+免责声明"）
10. **个人署名与研究视角质检**（补充规范V1.1第3节）：
    - hero-meta包含"作者：王知远"
    - Article schema的author是Person类型，name=王知远
    - 有研究者手记模块（基于真实地方志阅读经历，100-150字）
    - OG标签包含article:author=王知远
11. **素材库调用质检**（补充规范V1.1第10节）：
    - 调用了2-3个价值观标签
    - 调用了2-3个写作手法（不超过4个）
    - 主题有争议时调用了观众质疑模块（1-2个）
    - 结尾使用了首尾呼应或开放式余味（不是千篇一律的总结）

**输出**：
- 质检报告（通过/不通过，不通过项清单）
- 修改后的文章（如有不通过项）

**通过标准**：
- [ ] 创作规范V1.4的6大类质检全部通过
- [ ] 补充规范V1.1的检查清单全部通过
- [ ] 参考资料泛化条目数为0
- [ ] 文风一致性质检通过（7层控制体系）
- [ ] 禁止事项质检通过（无抽象范式句、无正文免责式表述、无内部编号展示、无模板化表达）
- [ ] 个人署名与研究视角质检通过
- [ ] 素材库调用质检通过
- [ ] 修改冻结规则生效（五点回查通过后进入冻结状态）

### 阶段5：GEO/SEO优化

**使用规范**：《补充规范V1.1》第4-8节（内链、文件名、技术SEO、服务转化、图片、内容结构）+ 第12节（禁止事项）

**输入**：
- 阶段4质检通过的文章
- 已有文章列表（用于内链检查）

**操作步骤**：
1. **文件名规范化**（补充规范V1.0第4节）：
   - 格式：`GEO-[大类编号]-[小类编号]_[标题关键词].html`
   - 中文文件名，不用拼音
   - 编号规则：GEO-01（岁时节令+人生仪礼）、GEO-03（民间信仰+祭祀制度）、GEO-04（族群文化+地域风俗）、GEO-05（社会历史+人口现象）、GEO-06（旧文改造）

2. **技术SEO标签检查**（补充规范V1.0第5节）：
   - meta description（150-160字，含关键词，问题式开头）
   - canonical URL（含域名）
   - OG标签（title/description/image）
   - Twitter card（summary_large_image）
   - Article schema（headline/datePublished/author/image）
   - Breadcrumb schema（首页→风物知识库→本文）
   - FAQ schema（至少3个问答对）
   - h1唯一且问题式，h2-h4层级清晰

3. **内链互引**（补充规范V1.0第3节）：
   - 检查与已有文章的主题重叠
   - 在overview-card或article-lead之后添加 `<p class="related-read">`
   - 每篇至少1个内链，最多3个
   - 双向互引（A链B，B也要链A）
   - 锚文本使用目标文章的完整标题

4. **图片优化**（补充规范V1.0第7节）：
   - 文章头图：1200×600，大小<200KB，alt属性含关键词
   - 首页主图（如涉及）：<500KB，JPEG质量60-70%
   - SVG信息图（长文建议）：含标题、数据来源、图例

5. **内容结构检查**（补充规范V1.0第8节）：
   - 新文标准结构：header→hero→container(overview-card→related-read→正文→FAQ→cta-section)→footer
   - 旧文改造标准结构：header→main(article-wrap)→breadcrumbs→article-kicker→h1→article-lead→related-read→article-meta→article-body→cta-section→footer

6. **服务转化检查**（补充规范V1.0第6节）：
   - 文章底部有转化区域
   - 文案使用"传统民俗日期咨询"
   - 链接指向 /guide-form

**输出**：
- 优化后的HTML文件
- 内链更新记录（涉及的其他文章也需要更新）

**通过标准**：
- [ ] 文件名是中文（GEO-XX-XX_关键词.html）
- [ ] 11项技术SEO要素全部齐全
- [ ] 至少1个内链，双向互引
- [ ] 图片大小符合规范
- [ ] 内容结构符合标准模板

## 六、常见问题与注意事项

### Q1：三个规范有冲突时以哪个为准？
A：以《补充规范V1.0》为准。补充规范是在实际优化过程中总结的最新经验，优先级最高。

### Q2：选题卡填了但写的时候发现史料不够怎么办？
A：回到阶段2补充史料，不得在史料不足的情况下强行写作。创作规范V1.4第1.11节明确要求：地方志直接记载不足时必须明确说明，不得用泛化条目充数。

### Q3：旧文改造走哪个流程？
A：旧文改造走阶段5（GEO/SEO优化）→ 阶段6（部署上线），但需要先做一次阶段4（内容质检）确认内容质量。旧文改造统一使用GEO-06编号，必须添加301重定向。

### Q4：内链互引怎么确保双向？
A：在阶段5添加内链时，必须同时更新目标文章的内链。建议维护一个内链关系表，记录每篇文章的内链情况。

### Q5：修改冻结规则是什么意思？
A：创作规范V1.4第1.8节规定：质检通过后文章进入冻结状态，后续只允许修复事实错误、链接错误、排版错误或用户明确指定的文字，不得再次自由改写内容。这是为了避免逐轮修改产生新的范围和证据问题。

### Q6：产能规划是怎样的？
A：创作规范V1.4第八节规定：12个月1000篇，每天2篇（1篇核心/长尾文 + 1篇FAQ短文）。核心文创作时间2-3小时，FAQ文30-60分钟。
