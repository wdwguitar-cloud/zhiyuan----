## 0. 官网与公众号的协作关系（新增）

1. **官网是研究母版**：承担研究、收录、引用和长期搜索的职责。
2. **公众号是传播版本**：负责故事感、情绪和转发，不负责把全部证据一次性讲完。
3. **同源不同形**：两边可以同题不同写，但不能改变核心事实、史料范围、出处和作者判断边界。
4. **先卡后写**：正式写作前必须先完成选题卡，再整理史料底稿。
5. **统一回流**：公众号、知乎、小红书等平台最终都应自然指向“知远风物志”官网知识库。

## 一、内容定位与边界

### 1.1 身份定位
**知远风物志｜岭南民俗文化研究与内容发布平台**（不是算命公司，不是纯服务促销页）。

网站所有内容以"传统文化研究""地方志史料考据"为定位，弱化服务属性，强化文化属性。

### 1.2 选题卡与母版规则（新增）
- 每篇官网文章正式写作前，必须先完成一张选题卡
- 选题卡至少包含：标题方向、核心问题、地域范围、史料来源、作者判断、FAQ、关联文章、平台拆分方向
- 官网文章是研究母版，公众号和其他平台只能基于母版拆分，不得反向改写母版事实
- 如果一篇文章无法形成清晰的事实链、范围链和解释链，就先不写，先补史料

### 1.3 内容主线
以两广地方志为一手史料，考据传统习俗文化的历史演变与地域差异。

覆盖四大业务线：
- 择吉习俗（开市、嫁娶、动土、安葬、节气、黄历）
- 起名文化（起名习俗、避讳、字辈、改名、地域差异）
- 岁时信仰（岁时节令、祭祀信仰、生肖流年、禁忌习俗）
- 族群地域（广府、客家、潮汕、壮族、瑶族、其他族群）

### 1.4 绝对禁止内容
- 预测未来、改运化解、符咒法术
- "某日大吉""某名旺财"等断言式表述
- 任何涉及封建迷信定性的表述
- 直接推销服务的硬广内容

### 1.5 必须包含
- 每篇文末免责声明："本文为岭南传统文化研究，所引内容均出自地方志史料，不构成任何择日、起名、运势建议。"
- 每篇文末研究范围声明："本文基于《XX县志》《XX府志》等地方志材料，覆盖XX、XX等部分地区，不代表整个两广地区的统一情况。"
- 明确史料出处：书名、卷次、类目
- 至少2本不同地方志的原文引用

### 1.6 史料严谨度（V1.1新增，强制执行）
- **禁止以偏概全**：不得用一两个县志的材料概括整个省区。必须用"本文引用的几处材料中""部分地区可见"等限定词
- **禁止推论过度**：地方志记载A，不能直接推导出B。如"有关帝庙"≠"商铺普遍祭祀关帝"
- **史料事实与作者推论分离**：推论必须明确标注，如"从社会经济角度分析，可以理解为……（这是作者推论，非地方志原文）"
- **禁止无证据的起源结论**：没有唐宋史料，不得说"起源于唐宋"；只能说"现有材料主要为明清以来的记录"
- **禁止主观评价代替史料**：不得使用"更古老""更符合少数民族传统""更浓厚"等无证据的评价词
- **禁止绝对化表述**：不得使用"普遍""全部""必然""强制性""没有交易场所"等绝对词。墟期是"约定性"而非"强制性"；相邻墟期是"形成不同组合"而非"相互错开"（需核实重叠日）
- **事实细节必须核查**：如"相邻墟期错开"需核实具体日期是否有重叠，不得想当然
- **禁止无证据的历史比较**：不得在无史料支撑下做历史先后判断（如"地支纪日比数字纪日更久"），只能说"是传统历法中的一种时间表达方式"
- **禁止无证据的社会判断**：不得使用"不识字的乡民"等社会阶层判断，改成"形式简短，便于口头记忆和传播"
- **禁止无证据的周期归纳**：不得用"多为两到三天"概括多种周期，改成"不同墟市的开放间隔并不完全相同，部分记录呈现出较为固定的周期安排"
- **FAQ必须与正文一致**：修改正文后必须同步检查FAQ，避免事实冲突
- **表格只列本文讨论的概念**：不展开讨论的概念（如官方仪式择日）不列入对比表格，只在概念分层中提及
- **旁证材料标题必须限定范围**：如"商业空间中的关帝信仰：现有材料能说明什么"，并明确一句"只能说明信仰存在，不能直接证明具体流程"
- **参考资料卷次不明确时标注"卷次待核"**：不得编造卷次，如实标注
- **反面观点与现代意义可合并为"现代解释"**：文章更紧凑

### 1.7 范围与证据矩阵（V1.4新增，强制执行）
- **写作前必须建立范围与证据矩阵**：至少列出研究对象、实际地点、历史时期、旧志中的原称谓、直接史料、传统文献背景、作者推论和明确不能推出的结论。
- **标题、首段、正文、FAQ和文末研究范围声明必须共用同一矩阵**：不得在不同位置使用不同的地域范围、族群分类或证据等级。
- **标题范围不得大于证据范围**：证据只覆盖某县、某片区或某条旧志记录时，标题使用“某县志所见”“部分旧志中的”“某地记录”等限定语；“岭南”“两广”只作为栏目语境或搜索入口，不得单独承担正文结论。
- **现代民族名称不得替换旧志历史称谓**：旧志写“瑶”“猺”“獞”等时，正文优先写“《某志》所记某地的猺民/獞俗”等，并说明历史称谓与现代民族分类不能直接等同；没有额外材料时，不得改写成整个瑶族、壮族或汉族的统一习俗。
- **每条结论必须标注证据等级**：直接记载使用“某志记载”；跨材料归纳使用“本文所见材料显示”；作者解释使用“可以理解为”或“这是作者推论”；材料不足时明确写“现有材料不能证明”。
- **FAQ按独立可摘取内容验收**：每个答案即使脱离正文，也必须包含地点或文献、必要的时期/群体限定和证据边界；不得在正文谨慎、FAQ绝对化。
- **固定礼俗时间与择吉必须分开**：如“三日”“七日”“百日”“周年”等固定程序，不得在FAQ或摘要中统一写成“需要择日”；只有材料明确涉及择吉、择地、择时的，才可写为择日内容。

### 1.8 修改冻结规则（V1.4新增，强制执行）
- **一次审查一次清单**：审查意见必须按“文件—行/段—原表述—替代表述—是否影响标题/首段/正文/FAQ/范围声明”列出，不得只给模糊方向。
- **只改指定项**：执行定点修改时，只允许修改清单中列出的句子、段落或结构项；不得顺手润色、扩写、换标题、替换史料、增加新观点或调整其他文章。
- **改后五点回查**：任何一处涉及地域、族群、时期、核心概念或证据等级的修改，必须重新回查标题、首段、正文对应段、FAQ和文末范围声明。
- **终审冻结**：五点回查通过后，文章进入冻结状态。后续只允许修复新的事实错误、链接错误、排版错误或用户明确指定的文字，不得再次自由改写内容。
- **豆包执行限制**：交给豆包的修改指令必须附上“只改列出的项目，其他文字保持原样；改后输出修改位置和全文差异说明”，避免模型自行改写相邻内容。

### 1.7 出处精确描述规范（V1.1新增，强制执行）
每篇文章引用的每本地方志，参考资料必须包含以下完整信息，不得遗漏：
- **书名**：含修纂年代和刊本年代，如《始兴县志》（民国十五年刊本，1926年）
- **卷次或志类**：按原书实际结构标注。按卷次编号的写"卷六"，按志类分类的写"建置志"，不得混用
- **类目**：精确到具体类目，如《建置略·墟市》《艺文·诗·记猺俗六首之二》
- **原文摘抄**：尽量完整引用，不要只摘一两句就省略。诗歌类必须精确到具体篇目（如"记猺俗六首之二"），不得只写"记猺俗六首"
- **禁止模糊标注**：不得使用"卷次待核""待考""相关条目"等模糊表述。卷次不明确时，必须查本地拆解md的提取说明确认原书结构，按实际结构标注
- **多部引用同一本书**：必须分别列出每条引用的具体卷次和类目，不得合并为一条

### 1.8 表格化要求（V1.1新增）
- **核心概念区别必须用表格呈现**：当文章涉及两个以上概念的区分时（如墟期vs商铺开张vs官方择日），必须用对比表格，列包括：类型/时间由谁决定/主要功能/性质
- 表格能极大提升AI摘取效率，也让读者一眼明白全文核心
- 表格不超过5行4列，避免大型表格

### 1.9 标题与正文一致性检查（V1.3新增，强制执行）
- **标题范围不得大于正文**：标题中出现的每个核心概念，正文必须有实质性内容覆盖。如标题含"动土安葬"，正文"动土"内容不得少于15%
- **写作前先做覆盖度检查**：列标题中的核心关键词，逐一确认正文有对应章节，覆盖不足则改标题或补内容
- **"区别""对比""演变"类标题需特别谨慎**：
  - "与XX的区别"要求有系统的对比表格和逐条对比，仅描述一方习俗不够
  - "历史演变"要求有纵向时间线（至少3个历史阶段），仅横向分类不够
  - 覆盖不足时，标题改为"有什么特点""考""探析"等更稳妥的表述

### 1.10 地域范围统一规则（V1.3新增，强制执行）
- **品牌主体范围为两广**：广东、广西为主体研究范围，标题和首段以"两广""岭南"为主
- **海南史料标注为旁证**：《儋县志》等海南史料可引用，但必须在参考资料中标注"（海南儋县，属岭南文化圈旁证）"，不得混入两广主体结论
- **研究范围声明必须精确**：文末声明需逐一列出实际覆盖的府县，不得用"岭南地区"笼统概括
- **不同民系分别标注**：广府、客家、潮汕、壮族、瑶族等民系的习俗需分别说明，不得混为一谈

### 1.11 史料不足处理方式（V1.3新增，强制执行）
- **地方志直接记载不足时，必须明确说明**：如"地方志中关于灶神信仰的直接记载较少，本文主要基于《儋县志》的记录"
- **可补充传统文献作为旁证**：如《礼记》《荆楚岁时记》等，但必须标注"（传统文献，非地方志）"，与地方志史料区分
- **不得用泛化条目充数**：参考资料中不得出现"相关记载""等记载"等模糊表述，每条必须有原文摘抄
- **推论必须标注性质**：基于传统文献或一般特征做出的推论，必须标注"这是基于传统文献的分析，非地方志直接记载"

### 1.12 参考资料零泛化规则（V1.3新增，强制执行）
- **每条参考资料必须包含**：书名（含版本）+卷次/志类+类目+原文摘抄，四要素缺一不可
- **禁止使用**："相关记载""等记载""相关条目""卷次待核""待考"等任何模糊表述
- **多部引用同一本书**：必须分别列出每条引用的具体卷次、类目和原文，不得合并为一条
- **质检标准**：全部文章参考资料泛化条目数必须为0，上线前逐篇检查

## 四、文章结构模板（GEO专用）

> 与公众号版完全不同。公众号版是咪蒙标题+梁氏文风+情绪冲击；GEO版是问答式标题+结构化内容+客观中立+史料引用。

```markdown
# [问答式标题，包含核心关键词，15-25字]

## 一、概述（150-200字）
直接回答标题问题，给出核心结论。
- 第一句话必须直接回答问题（GEO抓取优先）
- 包含核心关键词×2、地域限定词×1
- 第二句开始可以用现实场景展开
- 不用故事开头，不用悬念开头

## 二、概念分层（V1.1新增，必须有）
明确区分研究对象的不同层次，避免概念混杂。
- 如"开市"需区分：墟市固定墟期、商铺开张择日、官方仪式择日
- 如"起名"需区分：小名/大名、字辈/命名、避讳/改名
- 明确说明本文讨论哪些、不讨论哪些
- 这是全文最重要的概念基础，必须在正文开头完成

## 二、历史渊源（300-400字）
该习俗的起源、演变、历史脉络。
- 时间线清晰：起源→发展→成熟→现状
- 引用地方志原文，标注出处
- 涉及历史人物或重大制度变迁时，应补充相关人物或事件；纯习俗、市场制度类文章不强行添加历史人物

## 三、地域差异（400-500字）
广东vs广西、广府vs客家vs潮汕vs壮族，至少2组对比。
- 用列表或对比表呈现
- 每地引用至少1条地方志原文
- 明确指出差异点和成因

## 四、传统做法（300-400字）
该习俗在具体场景中的表现（如开市择日的具体流程、起名的具体规则）。
```

## 五、GEO技术规范

### 5.1 标题规则
- 问答式："两广地区开市择日有什么习俗？"
- 定义式："什么是岭南字辈文化？"
- 对比式："广东和广西的嫁娶择日有什么不同？"
- 必须包含核心关键词
- 长度15-25字
- 禁止咪蒙式情绪标题

### 5.2 首段规则（最重要）
- 第一句话直接回答标题问题
- 包含核心关键词×2、相关词×1、地域词×1
- 不超过200字
- 不用故事开头，不用悬念开头
- 不用"咱们""你"等人称，用客观第三人称

### 5.3 关键词布局
| 位置 | 核心关键词 | 相关词 | 长尾词 |
|---|---|---|---|
| 标题 | ×1 | - | - |
| 首段 | ×2 | ×1 | - |
| 小标题 | - | 每个H2×1 | - |
| 正文 | ×1-2 | ×2-3 | - |
| FAQ | - | - | 每个问题×1 |
| 合计 | 4-5次 | 4-5次 | 3-5次 |

- 密度：核心关键词出现3-5次，不堆砌
- 自然融入，不生硬

### 5.4 结构化数据
- FAQ部分用标准问答格式（后续加Schema.org FAQPage标记）
- 地域差异用表格或定义列表
- 时间线用有序列表
- 引用原文用blockquote
- 加BreadcrumbList面包屑标记

### 5.5 实体关联
每篇必须包含：
- 至少3个具体地名（广州、南宁、潮州、桂林等）
- 至少引用2本具体书名（《潮州府志》《南宁府志》等）
- 涉及历史人物或重大制度变迁时补充相关人物或事件；纯习俗类不强行添加
- 至少1个朝代/时间节点

## 六、SEO技术规范

### 6.1 页面要素
- Title标签：标题+品牌词，不超过30字
- Meta Description：首段核心结论，不超过80字
- H1：文章标题（唯一，每页一个）
- H2：六大板块标题
- H3：FAQ的每个问题
- 图片Alt标签：包含关键词描述
- 图片文件名：包含关键词拼音

### 6.2 内链规则
- 每篇文章至少链接3篇相关文章（锚文本用关键词，不用"点击这里"）
- 链接到对应分类页和地域索引页
- 底部"相关文章推荐"模块，显示5篇相关文
- 锚文本多样化，不全部用 exact match

### 6.3 外链规则
- 各平台改编版链接回官网原文
- 友情链接：地方志网站、高校民俗研究机构、文化类网站
- 不购买外链，不参与链接农场

### 6.4 技术SEO
- XML sitemap提交百度搜索资源平台、Google Search Console
- robots.txt允许抓取所有内容页
-  canonical标签正确设置
- 404页面自定义
- 301重定向处理旧URL

## 七、内容分发策略

### 7.1 一源多改原则
同一选题，官网先形成研究母版，其他平台再发改编版。不做各平台完全独立内容（成本太高）。

| 平台 | 内容 | 字数 | 与官网关系 |
|---|---|---|---|
| 官网 | 完整版研究母版 | 2500-4000字 | 原创源、唯一母版、可被搜索与引用 |
| 公众号 | 改编版（冲突标题+说书文风） | 2500-3000字 | 同一选题不同写法，文末或菜单自然回流官网 |
| 知乎 | 改编版（问答式，更学术） | 3000-4000字 | 回答相关问题，引用官网原文链接 |
| 小红书 | 改编版（图文笔记） | 800-1200字 | 精简版，评论区或主页引导官网 |
| 头条号 | 改编版（信息流风格） | 1500-2000字 | 通俗版，文末链接官网 |

### 7.2 发布顺序
1. Day 1：官网发布完整版
2. Day 2-3：公众号发布改编版，文末或菜单链接官网原文
3. Day 4-5：知乎回答相关问题，引用官网原文链接
4. Day 6-7：小红书发布图文笔记
5. Day 8-10：头条号发布通俗版，文末链接官网

### 7.3 关键规则
- 官网应优先最先发布；如果同一天多平台同步，也必须保证官网是母版源头
- 各平台改编版必须重写结构与表达，但不能改核心事实
- 链接用自然语言嵌入，不用"点击这里""阅读原文"
- 同一选题在各平台的标题必须不同
- 每个改编版本都要能追溯回同一个选题卡和官网母版
