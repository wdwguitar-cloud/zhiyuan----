# 顾问介绍页传记仪式感美化设计说明

日期：2026-08-13
项目：择日择吉项目
页面：`/advisor.html`
状态：已确认方向，待用户检查文档后进入实现

## 1. 目标

本轮只优化顾问介绍页的视觉表达，不改页面信息结构，不改站内其他页面，不新增功能。

用户明确希望：

- 强化“人物传记感”和“仪式感”
- 优化“易学世家 / 虔诚皈依 / 授业解惑 / 立身之器”这四个文本框
- 连同本页下方其他文本框一起统一美化
- 标题字体不要过大

## 2. 范围

本轮只处理以下顾问介绍页区域：

1. 左侧人物信息区中四张经历卡片
2. 右侧“服务介绍”主信息卡
3. 中段三张流程说明卡
4. “适合承接哪些咨询”区块
5. 页面底部咨询承接区中的说明卡片

本轮不处理：

- 全站导航
- 首页
- 年度顾问页
- 案例页
- 内容文案改写
- 新增交互或新页面跳转

## 3. 设计方向

采用“传记仪式感”方案。

核心判断：

- 不做重装饰卷轴风，避免与现有站点脱节
- 保留现有酒红、米金、米白主基调
- 通过比例、留白、边框、光泽、层次来建立更稳的文化感
- 让页面更像“人物传记页 + 顾问信任页”，而不是普通介绍页

## 4. 视觉策略

### 4.1 四张经历卡

“易学世家 / 虔诚皈依 / 授业解惑 / 立身之器”将作为本页最核心的传记模块处理：

- 卡片留白增大
- 标题缩小一档，减少压迫感
- 标题与正文拉开层级，不再只靠字重
- 增加更克制的顶部金线或角标式点缀
- 调整卡片底色层次，让其比普通说明卡更精致
- 保持移动端阅读舒适，避免单卡内文字过满

目标是让这四张卡更像“人物生平节点”。

### 4.2 下方说明卡统一

顾问介绍页下方多组文本框目前语言统一，但卡片气质还不够集中。

本轮会统一：

- 圆角尺度
- 面板明暗层次
- 内边距与段落节奏
- 小标题字级和字重
- 分隔线和顶部细节点缀

目标是让整页形成一套连续的卡片系统，而不是几组独立模块拼接。

### 4.3 标题系统收口

用户明确要求“标题字体不要太大”。

因此本轮会：

- 将四张经历卡标题明显缩小
- 适度下调部分区块标题的视觉攻击性
- 保留重点标题的识别度，但不再用过大的字号抢占版面
- 让正文成为真正可读的主体，而不是被标题压住

## 5. 保留项

以下内容本轮不改：

- 页面文案内容本身
- 页面结构顺序
- 按钮文案和按钮跳转逻辑
- 内容库数据接入方式

## 6. 实现落点

预计主要修改：

- `app-frontend/src/pages/AdvisorPage.jsx`
- `app-frontend/src/index.css`

实现方式：

- 优先通过局部 class 结构整理与新增样式类完成
- 不大改现有数据结构
- 不对其他页面通用卡片系统做高风险破坏

## 7. 验收标准

完成后应满足：

1. 四张经历卡明显更精致，且更有“人物传记节点”气质
2. 下方文本框视觉统一，不再像松散的默认卡片
3. 标题整体收敛，阅读压力降低
4. 仍保持当前品牌体系的酒红、米金、米白调性
5. 手机端显示稳定，不出现文字拥挤或层级混乱

## 8. 风险控制

本轮最大风险是为了追求“仪式感”而做得过重。

因此本次实现会控制在：

- 有明显提升
- 但不过度复古
- 不引入花哨装饰
- 不破坏现有站内统一风格

最终目标是“更庄重、更有文化底色、更耐看”，而不是“更复杂”。
