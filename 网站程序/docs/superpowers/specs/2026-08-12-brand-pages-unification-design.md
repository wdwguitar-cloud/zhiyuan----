# 全站品牌页统一设计方案

日期：2026-08-12
项目：择日择吉项目
范围：`/guide-form`、`/advisor.html`、`/annual.html`、`/cases.html`
状态：已确认，待进入实现

## 1. 背景

首页已经完成多轮视觉收口，当前方向已经明确为：

- 酒红 + 米金 + 米白面板
- 企业顾问感 + 仪式感
- 手机端优先
- 去模板味、去 AI 味

现阶段的问题不是首页单页不成立，而是站内其他高频页面仍然保留旧的营销页语言、专题页语言或占位页语言，导致用户从首页跳到其他页面时，会明显感觉不是同一个品牌站。

本轮目标不是单纯“换皮”，而是把高频页面统一到首页这套品牌体系下，同时保留每个页面各自的任务分工。

## 2. 目标

本轮设计与实现目标如下：

- 让 4 个高频页面继承首页同一套品牌语言
- 统一导航、标题、卡片、联系区、按钮和移动端体验
- 保留不同页面的任务分工，避免所有页面长得一模一样
- 继续降低模板感、组件拼装感和后台味
- 不改动既有后端校验和核心跳转逻辑

## 3. 本轮范围

本轮只处理用户最常看的 4 个页面：

1. `咨询领取页`：`/guide-form`
2. `顾问介绍页`：`/advisor.html`
3. `年度顾问页`：`/annual.html`
4. `案例中心页`：`/cases.html`

本轮不优先处理：

- `我的`
- `合作加盟`
- 其他占位页或次级页面

这些页面后续可在同一母版体系下继续补齐。

## 4. 统一策略

采用“统一骨架 + 页面有分工”的方案，而不是简单复制首页。

原因：

- 如果只换皮，不重排结构，页面仍会保留旧的信息组织问题。
- 如果完全复制首页，页面之间会过于雷同，案例页、咨询页、顾问页会失去各自功能性。
- “统一骨架 + 页面分工”最适合当前项目：既像同一个品牌站，又能让不同页面各司其职。

## 5. 品牌母版规则

本轮会先抽出一套全站共用的页面母版规则。

### 5.1 页面外壳

- 统一使用首页同一套深酒红背景基底
- 统一米白信息面板和深色承接区
- 统一顶部间距、区块节奏和页面底部安全留白
- 统一移动端固定底部导航与内容区之间的避让关系

### 5.2 标题系统

- 使用首页现有标题逻辑：主标题 + 简洁副说明 + 细金线分隔
- 取消到处出现的红色胶囊标签、花哨题眉和重复的小强调块
- 让标题承担信息权重，不依赖多余装饰

### 5.3 卡片系统

全站统一为 3 类卡片：

1. 米白信息卡
2. 深酒红承接卡
3. 轻量说明卡

规则：

- 不再出现厚重左侧彩色边线
- 不再依赖“编号 + 标签 + 强调条”制造层级
- 优先通过留白、对齐、字体和浅分隔建立秩序

### 5.4 按钮系统

统一 3 层关系：

1. 主按钮：米金系主行动
2. 次按钮：克制描边或浅底按钮
3. 弱按钮：纯文字或轻交互按钮

规则：

- 主按钮数量严格控制
- 次按钮不与主按钮抢戏
- 页面底部和固定导航不再同时出现多个同等级 CTA

### 5.5 联系区系统

统一以下元素的承接逻辑：

- 咨询入口
- 微信号
- 二维码
- 手机号
- 填表引导

规则：

- `/guide-form` 始终是主咨询承接页
- 其他页面的咨询动作统一尽量收口到 `/guide-form`
- 联系区呈现方式统一为“正式顾问承接区”，不再像临时功能块

### 5.6 移动端规则

- 首屏优先保证主标题、主按钮、主说明聚焦
- 固定底部导航弱化，不盖过正文
- 内容结尾自动留出安全区
- 避免一字一行、按钮拥挤、文字出框、内容贴边

## 6. 各页面的角色与重排方案

### 6.1 `/guide-form` 咨询领取页

页面角色：转化母版

目标：

- 让用户一进页面就明白“先填写资料，再领取/咨询”
- 让表单成为页面视觉中心
- 把微信联系区降级为辅助，不与表单抢主位

重排结构：

1. 简洁封面区
2. 表单主区
3. 领取前说明区
4. 微信补充联系区

设计原则：

- 减少多余引导文案
- 降低无用装饰
- 提高表单区的中心性和可信度

保持不变：

- 现有后端校验逻辑
- 姓名与 11 位手机号规则
- 既有跳转与提交方式

### 6.2 `/advisor.html` 顾问介绍页

页面角色：信任母版

目标：

- 让用户先信任顾问，再进入咨询
- 强化“人物 + 方法 + 边界 + 联系”的品牌逻辑
- 去掉开发入口感、占位页感

重排结构：

1. 左右双栏首屏  
   左边人物海报，右边顾问定位、简介与咨询入口
2. 为什么顾问页要单独存在
3. 顾问处理项目的方法
4. 联系与转化区

设计原则：

- 人物主位必须明确
- 卡片不再像功能模块堆叠
- 方法说明更像专业顾问表达，不像运营口播

保持不变：

- 顾问海报素材入口和内容中心链接可保留，但需降开发感
- 现有咨询入口逻辑不变

### 6.3 `/annual.html` 年度顾问页

页面角色：商务提案母版

目标：

- 让用户感到这是“长期顾问服务”，不是普通单次咨询页
- 更强调全年统筹、长期陪伴、复杂项目价值

重排结构：

1. 商务封面区
2. 为什么要年度顾问
3. 服务交付与陪伴方式
4. 联系承接区

设计原则：

- 视觉更稳重、更克制
- 信息结构更偏提案和方案感
- 不能再出现过于营销型的按钮堆叠

保持不变：

- 年度顾问服务方向
- 咨询跳转逻辑
- 已确认的核心表达方向

### 6.4 `/cases.html` 案例中心页

页面角色：展示母版

目标：

- 用真实案例建立信任
- 让用户快速理解场景、服务内容和结果
- 看完后自然进入咨询页

重排结构：

1. 顶部总览封面
2. 分类切换区
3. 案例摘要卡主区
4. 底部咨询承接区

设计原则：

- 分类清楚，但不过度花哨
- 卡片像“项目摘要”，不是图片拼盘
- 结果表达更像真实项目沉淀

保持不变：

- 既有案例分类方向
- 已确认的咨询收口方式

## 7. 实施顺序

按以下顺序执行：

1. 抽整理共用母版样式
2. 改 `/guide-form`
3. 改 `/advisor.html`
4. 改 `/annual.html`
5. 改 `/cases.html`
6. 做全站统一收口和编译验证

这样安排的原因：

- 先定转化页，统一咨询收口方式
- 再定信任页，统一顾问表达方式
- 再定商务页，统一长期服务气质
- 最后用案例页承接展示体系

## 8. 不做的事

本轮不包含以下内容：

- 修改后端接口协议
- 改动表单校验逻辑
- 更换咨询承接主路径
- 全站重新写文案
- 一次性重做“我的 / 合作加盟 / 其他占位页”

## 9. 风险与控制

### 风险 1：页面统一后变得过于雷同

控制方式：

- 骨架统一
- 页面角色区分
- 保留不同页面的信息组织差异

### 风险 2：移动端首屏被底部导航或过多按钮干扰

控制方式：

- 弱化底部导航存在感
- 控制每屏主按钮数量
- 保证内容区底部安全留白

### 风险 3：旧页面中仍残留模板化强调条、标签和开发入口感

控制方式：

- 清理明显左侧粗边、重复小标签、冗余编号
- 下调开发入口的视觉优先级
- 保证用户主路径优先

## 10. 验收标准

完成后应满足：

- 用户从首页进入 4 个页面，不会觉得跳到另一套网站
- 4 个页面都具备首页同级别的品牌统一感
- 每页仍保留各自功能分工，不会长得完全一样
- 移动端不出框、不贴边、不压字、不被底部导航遮挡
- 所有主咨询入口统一收口到既定路径
- 编译通过
- 页面相关 detector 无明显模板信号回归

## 11. 下一步

本设计文档确认后，进入实现阶段，先从 `/guide-form` 开始。
