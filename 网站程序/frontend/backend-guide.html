V5 全栈版本

后端接入说明

V5 已经内置 Node 后端。你本地启动后，网站、表单接口、线索后台、CSV 导出都在同一个地址下运行。

打开线索管理 提交测试线索

核心链路

用户填表 → POST /api/leads → 保存 JSON/CSV → 可选推送飞书/企微 → admin.html 读取数据。

本地启动

不要直接双击 index.html。V5 要通过后端服务访问。

cd backend npm install npm start 然后打开： http://localhost:8787

.env 配置

复制 backend/.env.example 为 backend/.env 后修改。

PORT=8787 ADMIN_TOKEN=change-this-admin-token # 可选：飞书 / 企业微信机器人 WEBHOOK_URL= WEBHOOK_TYPE=generic # 可选值：generic / feishu / wecom

接口说明

POST /api/leads

接收表单线索，保存到 JSON 和 CSV，并可选推送 Webhook。

GET /api/leads

后台读取线索。正式上线建议设置 ADMIN_TOKEN。

GET /api/leads.csv

下载服务器端 CSV 文件，用于导入表格。

部署建议

宝塔 / 云服务器

适合国内业务，Node 服务长期运行，前端和后端同站部署。

Render / Railway

适合快速测试海外部署，直接运行 backend/server.js。

飞书 / 企业微信

用 WEBHOOK_URL 把新线索推送到群，方便家庭成员及时跟进。

V6 运营后台新增接口

V6 不只是收线索，还可以保存跟进状态和成交信息。

PATCH /api/leads/:id

保存状态、跟进备注、标签、成交金额和下次回访时间。

CSV 完整导出

导出字段包含留言、跟进备注、标签、成交金额、回访时间。

运营后台

admin.html 现在就是轻量 CRM，可用于家庭团队初期跟进。
