199 资料初审报告模板

用于低门槛成交后，判断客户项目类型、资料完整度、服务档位和下一步建议。

一、客户项目基础资料

  • 项目类型：厂房 / 门店 / 办公室 / 工地 / 公司乔迁 / 其他。
  • 所在城市：仅记录城市或区域，公开案例不写详细地址。
  • 计划时间：7 天内 / 15 天内 / 30 天内 / 未确定。
  • 咨询人身份：老板本人 / 公司负责人 / 家人代问 / 施工方代问。
  • 当前需求：日期时辰 / 完整流程 / 上门指导 / 只想先了解。

二、资料完整度判断

  • 是否明确项目类型。
  • 是否明确开工事项：装修、动土、开业、搬迁、入驻或施工进场。
  • 是否明确负责人是否到场。
  • 是否确认施工方、物业或现场负责人能否配合。
  • 是否存在时间冲突、施工限制或现场特殊情况。

三、初步判断

  • 如果项目简单、时间清楚、施工方可配合，可进入 999 日期与时辰咨询。
  • 如果涉及现场流程、人员分工、供品、施工方和负责人协调，建议 2980 完整流程方案。
  • 如果项目较大、需要多节点安排或上门，可单独评估。
  • 如果资料不足，先补齐资料再判断，不建议直接出正式方案。

四、交付边界

  • 本初审只判断资料和服务方向，不等于正式择日。
  • 工程施工、安全、消防、物业、审批问题由客户和相关专业人员确认。
  • 不承诺经营收益、投资回报、工程结果或特定效果。
