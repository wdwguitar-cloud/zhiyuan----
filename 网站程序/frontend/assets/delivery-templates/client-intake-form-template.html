成交后客户资料收集表模板

用于客户付款后补齐正式方案所需资料。网页初筛表单不要收太多隐私信息，成交后再用这份表。

一、基础信息

  • 客户称呼。
  • 联系方式。
  • 项目所在城市和区域。
  • 项目类型：厂房 / 门店 / 办公室 / 工地 / 乔迁 / 其他。
  • 开工事项：装修 / 动土 / 开业 / 搬迁 / 入驻 / 施工进场。

二、时间信息

  • 计划开工时间范围。
  • 必须避开的日期或时段。
  • 施工方可配合时间。
  • 物业或园区允许施工时间。
  • 老板或负责人可到场时间。

三、现场信息

  • 开工位置是否已确定。
  • 施工方或物业是否已确认。
  • 是否有特殊作业、设备进场、吊装、动火等情况。
  • 是否需要上门。
  • 是否需要拍照记录和案例素材整理。

四、民俗咨询信息

  • 是否需要结合负责人信息判断。
  • 是否有客户自身避忌。
  • 是否有地方习俗要求。
  • 是否需要供品和流程建议。
  • 是否需要完整人员分工。

五、确认声明

  • 客户确认所提供资料真实、完整。
  • 客户确认施工、安全、消防、物业、审批由客户和专业人员确认。
  • 客户确认本服务不承诺经营收益、投资回报或工程结果。
本模板仅供商业开工民俗咨询服务参考，请根据真实项目资料调整；不替代工程施工、安全管理、法律审批或专业技术意见。
